# 我的学术主页

访问地址：**https://sunhexiang2026.github.io/**

这是 GitHub Pages 上的公开静态网站，电脑和手机均可使用浏览器打开，不需要购买域名或登录本站。保留雪山横幅、学术主页栏目、文章阅读、知识库、搜索及手机布局。

个人简介、现职与学术邮箱由本人提供并授权公开。论文栏目已收录第一篇 SCI 论文：Chinese Physics B 34(5), 050308 (2025)，DOI: 10.1088/1674-1056/adc662。博客中的三篇建站示例不代表真实经历或成果；知识点和研究经验保持为空。

## 管理网站

登录自己的 GitHub 账号，打开本仓库，选择文件后点击铅笔按钮编辑，最后点击 **Commit changes** 保存。GitHub Pages 构建完成后网站自动更新；进度在仓库的 Actions 页面查看。

| 要修改什么 | 文件 |
| --- | --- |
| 新增、编辑、删除文章 | `posts.js` |
| 个人资料、邮箱与论文元数据 | `profile.js` |
| 主页介绍与栏目布局 | `homepage.js` |
| 论文引用文件 | `publications/` |
| 知识点与研究经验 | `knowledge.js` |
| 品牌、导航、页脚 | `index.html` |
| 图片、音视频 | `media/` 文件夹 |
| 页面样式 | `academic.css`、`style.css` |

文章可从 `posts.js` 中复制一个示例对象，修改 `id`、标题、日期、分类、摘要和正文。`id` 使用不重复的英文短横线名称；分类可以是 `notes`、`essay`、`life`；自己的文章将 `sample` 改为 `false`。对象之间保留逗号。

正文放在 JavaScript 反引号字符串内。正文中的反引号需要写成 `\``，字面量 `${` 需要写成 `\${`，否则文件会报错。编辑完成前建议本地预览。

## 文字、图片和公式

正文支持 Markdown 标题、列表、加粗、引用与代码块。图片先用仓库的 **Add file → Upload files** 上传到 `media/`，使用英文文件名，例如 `example.png`，然后在正文填写：

```markdown
## 一个小标题

这是 **重点内容**。

![图解说明](/media/example.png)

行内公式：$E=mc^2$。

$$
x^2+y^2=z^2
$$
```

公式中的反斜杠需要按 JavaScript 字符串规则写成双反斜杠。Markdown、公式渲染器和字体随本站一起托管，不依赖外部 CDN。知识库的结构化图解、表格、公式、自测和本地音视频展示功能仍保留，当前没有任何知识库条目。

GitHub Pages 不运行原来的云服务器后台：没有本站注册、账号审批、登录、草稿保存或上传接口。内容管理由 GitHub 账号权限控制，访问者只能阅读，不能修改本仓库。页脚“管理内容”链接会打开 GitHub。
